# Organic SEO implementation — October 15, 2026

## Audit before implementation

The clean checkout is a Next.js App Router application with React, TypeScript and static route generation. Inventory: 11 tools, six guides, six curated loan scenarios, four guide categories, homepage/tools/guides hubs and six information pages (36 HTML routes). There is no database, account system, live vehicle feed, keyword provider or Search Console reporting client. The only application endpoints are health, generated OG imagery, ads.txt and XML sitemap groups. Existing calculator, checklist, sharing, CSV, print and mobile behavior must remain intact.

Reviewed the route registry, metadata factory, layout, robots/root and grouped sitemaps, redirects/headers, structured data, tool/guide templates, content data, calculator evaluation, browser/unit checks and previous HTTP/Lighthouse evidence. Existing self-canonicals, query normalization, true 404s, staging noindex, SSR, contextual links and schemas are already implemented; retain and revalidate them. Three singleton guide collections intentionally remain noindex. Existing reports are historical evidence, not new measurements or live-domain findings.

## Prioritized implementation

1. Preserve existing technical safeguards; capture a fresh baseline and rerun HTTP checks after changes.
2. Refine existing inspection, loan and ownership search intent. Add private-seller questions, engine/mileage guidance and explicit print-to-PDF instructions to existing pages instead of competing new URLs. Keep model estimates clearly labeled.
3. Publish one international research guide with distinct UK, Australian, Punjab/Pakistan and Dubai/UAE sections, official resources, explicit regional scope and local units/currency limitations. This is a research hub, not four translated alternatives; no hreflang is warranted.
4. Add crawlable contextual links to the international resource, retain existing category/tool hubs, derive guide counts from data and record a real source-review date only for reviewed new content.
5. Map all 30 candidates with assigned intent, priorities and evidence gaps. No demand, difficulty or ranking metrics are available; mark them unknown. Defer model reliability and price-based lists rather than fabricate evidence or publish placeholder pages.
6. Validate lint, typecheck, unit tests, build, production HTML/sitemaps/schema, browser tools/print/mobile accessibility and the new guide without JavaScript. Report actual outcomes and external dependencies.

## Research boundaries

Official GOV.UK, Australian PPSR, Punjab Excise/ePay and Dubai RTA resources were researched on October 15, 2026. No fixed transfer fees, nationwide Pakistan/UAE process, live car prices, model reliability rankings or lender offers will be inferred from those sources. Source review is not professional review. Search Console verification support already exists; it does not grant access to performance reports.

## Execution notes

The attempted fresh pre-change HTTP baseline could not run because the current build did not have a prerender manifest. Historical October 14 evidence is retained; no fresh before/after performance delta is claimed. Overlapping edits briefly introduced duplicate guide registration during implementation. The existing uniqueness test caught it; the final registry includes the new guide once. The final route is `/guides/international-used-car-buying-checks`; `/international` is not published.
