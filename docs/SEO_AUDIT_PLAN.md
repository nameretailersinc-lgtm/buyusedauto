# SEO and deployment audit plan

1. Capture a production-build HTTP baseline for every content route, sitemap, status, canonical, robots directive, schema type and internal link.
2. Fix confirmed deployment/indexing risks, schema eligibility issues, and low-value collection indexing while preserving all functionality and layouts.
3. Add regression tests and stronger HTTP checks, run build/lint/unit/browser checks, and measure affected performance if needed.
4. Record affected URLs, before/after evidence, remaining external dependencies, and deployment instructions. Technical eligibility does not guarantee Google's indexing or rich-result decisions.

Scope: this repository contains automotive calculators, a checklist, guides and information pages. It contains no image-processing tools, text-processing tools, database, or application API integrations. Generated editorial images and the existing OG endpoint are included in the audit.
